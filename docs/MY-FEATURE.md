# MY-FEATURE — จังหวัดที่ทุนจดทะเบียนสูงสุด 5 อันดับ

## ผู้ใช้จะเห็นอะไรเพิ่ม

หน้าเว็บ Registry Insight จะมีการ์ดใหม่ต่อท้ายการ์ดเดิม: "จังหวัดที่ทุนสูงสุด (Top 5)" แสดงรายชื่อจังหวัดพร้อมทุนรวมของจังหวัดนั้น เรียงจากมากไปน้อย คำนวณจาก `data/dataset.csv` (คอลัมน์ `province` กับ `capital`) ผ่าน endpoint ใหม่ `GET /api/provinces/top`

## ไฟล์ที่อนุญาตให้แตะ

- `server.js` — เพิ่ม endpoint `/api/provinces/top` (อ่าน CSV ด้วยตัวอ่านเดิม เรียกข้อมูลผ่าน `analyze()` เดิมถ้าทำได้ หรืออ่านคอลัมน์ province/capital ตรง ๆ ก็ได้)
- `web/index.html` — เพิ่มการ์ดใหม่
- `web/app.js` — เรียก endpoint ใหม่แล้วเติมรายการลงการ์ด

## ห้ามแตะ

- `scripts/quality-gate.js` — ตัวตรวจตายตัว
- ยอดหลัก 16,772 กิจการ / 45,341,868,784 บาท — ห้ามทำเพี้ยน
- คีย์ใด ๆ — ไม่มีคีย์ในไฟล์
- `data/` — ข้อมูลสะอาดแล้ว ห้ามแตะ

## สายงาน (สองจังหวะ)

1. จังหวะแผน: ผู้ช่วยเขียน `docs/MY-FEATURE-TASKS.md` ลิสต์ไม่เกิน 5 ข้อ ห้ามแก้โค้ดรอบนี้
2. จังหวะทำ: ผู้ช่วยทำตาม `docs/MY-FEATURE-TASKS.md` เท่านั้น จบด้วย `npm run gate` ต้องยัง 6/6

## เสร็จเมื่อ

เปิด `npm start` แล้วเห็นการ์ด Top 5 จังหวัดจริงบนหน้าเว็บ และ `npm run gate` ยัง exit 0
