# Registry Insight - ความจำของแอป

## แอป Registry Insight
แอปนี้ใช้ข้อมูลจดทะเบียนใหม่ พ.ศ. 2558 (2015 AD) เพื่อจัดการข้อมูลระบบจดทะเบียน

## กติกาสำคัญ 5 ข้อ

1. **ทางขึ้นของจริงคือ `api/*.js`** ที่ผู้เรียนสร้างใน Lab 11 ไม่ใช่การเอา `server.js` ไปฟังพอร์ตบน Vercel

2. **ห้ามแก้ `scripts/quality-gate.js`** - ตัวตรวจตายตัวของระบบ

3. **ห้าม `git push` เอง** เว้นแต่ผู้เรียนสั่งหลังดู diff แล้ว

4. **ห้ามตั้งค่า API Key ผ่าน Environment Variables** บน Vercel
   - ห้ามตั้ง `ANTHROPIC_API_KEY` หรือ `OPENROUTER_API_KEY`
   - OpenCode อ่านค่าจาก `opencode.json` ผ่านตัวแปร `{env:OPENROUTER_API_KEY}`

5. **โน้ตบนเครื่องเขียนได้, โน้ตบน Vercel เป็นอ่านอย่างเดียว**
   - บนเครื่องผู้เรียน: โน้ตเขียนลง `data/notes.json`
   - บน Vercel: โน้ตเป็นอ่านอย่างเดียว

## ความต้องการในการเสร็จสิ้น
- ต้องผ่านด่าน 6/6 ก่อนบอกว่าเสร็จ
- ห้ามเพิ่ม dependency npm ใหม่
- ตอบเป็นภาษาของผู้ถาม
- ชื่อไฟล์, endpoint และชื่อฟิลด์คงภาษาอังกฤษ
- ห้ามอ่านหรือคัดลอกค่าที่ขึ้นต้นด้วย `sk-`
